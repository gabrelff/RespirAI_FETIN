## Descrição

Sistema de monitoramento não invasivo de gases expelidos pelo pulmão, desenvolvido para auxiliar no diagnóstico e acompanhamento de doenças respiratórias.

## Funcionalidades

- **Monitoramento em tempo real** dos gases CO, CH4, C2H5OH, H2, NH3 e NO2.
- **Conexão WebSocket** com ESP32.
- **Interface responsiva** servindo como dashboard para auxiliar médicos, enfermeiros e pacientes.

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript
- C++ (Arduino IDE)
- ESP32
